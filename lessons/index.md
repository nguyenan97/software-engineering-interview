# Lessons

Each lesson is a durable learning artifact, not evidence of completion. The [learning workflow](../docs/workflow.md) tracks attempts, assessments, completion, and review scheduling separately.

Ask **“Viết bài học hôm nay”** to select the next appropriate lesson using the [Daily Interview Mastery skill](../agent/SKILL.md). A generated lesson remains available for study; the agent must check history before creating another lesson with the same learning objective.

Use **“Ôn tập hôm nay”** for retrieval practice and **“Mock interview hôm nay”** for spoken-answer practice. Reviews are scheduled from actual completion rather than from the lesson creation date.
