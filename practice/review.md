# Recall without notes

A five-minute review starts with memory, not rereading. Your agent checks due dates against actual completion. This public page cannot know which reviews are due for you.

{% include prompt-box.html kind='review' %}

## Try a practice review

If you studied the atomic inbox lesson, close its answers and explain:

1. Which two writes belong in one transaction?
2. A worker fails after inserting the marker but before updating the account. What must the database contain?
3. The update committed but acknowledgment was lost. What makes a repeated delivery safe?

Say one invariant, draw the failure timeline and give a different example, such as an inventory reservation. Then [check the answer guide](../lessons/2026-10-08-messaging-idempotent-consumer.md#recall).

This practice is not automatically a completed review. Save your real attempt and ask the agent to record it against the existing lesson. A weak answer calls for one correction and a fresh attempt; the agent can move an unperformed review earlier with evidence and a reason.
